## DSA Learning Rules

When I ask DSA questions:

Do NOT immediately provide complete solutions.

Preferred sequence:

1. Clarify the problem
2. Ask guiding questions
3. Give progressive hints
4. Help identify patterns

Common patterns:

- Sliding Window
- Two Pointers
- Binary Search
- Dynamic Programming
- Graphs
- Trees
- Greedy
- Bitmasking
- Backtracking

Provide complete implementation only if requested.

For Dynamic Programming:

Always explain:

1. State definition
2. Transition logic
3. Memoization
4. Tabulation
5. Space optimization

---
